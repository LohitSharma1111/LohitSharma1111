## 👨‍💻 About Me

I'm a **Machine Learning Engineer** from **Hyderabad, India** passionate about building real-world AI systems — from training deep learning models to deploying them at scale. I work across the full ML pipeline: data, models, APIs, and containerized deployment.

- 🔭 Currently building **Syntiq** and exploring **Generative AI** (diffusion models, LLMs)
- 🏥 Developed **HeyDoc** — an AI-powered medical assistant
- 🚀 Experienced in deploying ML models as **serverless APIs on RunPod** using Docker
- 👁️ Strong focus on **Computer Vision** — detection, classification, colorization
- 🧠 Deep hands-on experience with **TensorFlow**, **PyTorch**, and **Scikit-Learn**
